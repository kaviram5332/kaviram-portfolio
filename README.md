# Kaviram — Software Developer Portfolio

A modern dark-mode portfolio built with React 19, TypeScript, Tailwind CSS v4, Framer Motion, and an 85-frame scroll-driven HTML5 `<canvas>` background sequence.

## Features

- **Scroll-Driven 85-Frame Background**: Smooth `requestAnimationFrame` lerp-interpolated portrait sequence mapped across the page scroll with an interactive `PREVIEW / PAUSE` control.
- **Minimal Luxury UI**: Translucent `</> Developer` header, glassmorphic cards, neural particle backdrop, and responsive mobile-first layout.
- **Sections**: Hero Introduction, About & Mission, Scroll-Reactive Career Timeline, Recognition & Open Source, Interactive Contact Form, and downloadable PDF Resume (`public/Kaviram_Resume.pdf`).

## Getting Started

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```
